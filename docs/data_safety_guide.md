# Data Safety（データ安全性）フォーム記入ガイド

このドキュメントは Play Console の Data safety セクションに記入する際の参考です。

1) 収集するデータ
  - 広告識別子（Advertising ID）: 収集する（広告配信・測定のため）。
  - 端末情報（非個人）: 例: OS バージョン、デバイスモデル（分析目的に限定）。
  - ユーザーによる明示的な入力データ: なし（本アプリは歌詞ファイル等のローカル読み込みのみ）。

2) 第三者への共有
  - 広告ネットワーク（Google AdMob）へ広告識別子を送信します。
  - それ以外の個人データは第三者送信しない想定。

3) 用途（用途カテゴリ）
  - 広告配信: はい（Advertising ID）。
  - アナリティクス: （該当する場合）使用する場合はその旨を明記。

4) 暗号化・保存期間
  - 収集する識別子は端末レベルで管理され、サーバーに保存しない設計が望ましい。必要な場合は保存期間と利用目的を明記。

5) オプトアウト方法
  - ユーザーは端末の広告設定で広告識別子のリセットや広告パーソナライズの制限が可能であることを明記。

6) 推奨アクション
  - Play Console の Data safety の各項目（Collected data, Shared, Purpose, Security）に沿って、上記を簡潔に入力してください。
