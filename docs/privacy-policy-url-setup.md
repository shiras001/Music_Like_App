# プライバシーポリシー URL の作り方（最短）

`docs/privacy-policy.md` を公開 URL 化する手順です。

## 方法A: GitHub Pages（無料・簡単）

1. このリポジトリを GitHub に push
2. GitHub リポジトリの `Settings > Pages` を開く
3. `Build and deployment` を以下に設定
   - Source: `Deploy from a branch`
   - Branch: `main`（または運用ブランチ）
   - Folder: `/docs`
4. 数分待って発行されたURLを確認
5. Play Console の「プライバシーポリシー URL」に設定

## 方法B: Notion / Google Sites / 任意のWebホスティング

`docs/privacy-policy.md` の内容を貼り付けて公開し、公開URLをPlay Consoleへ設定します。

## 提出前チェック

- Play Console の「データ セーフティ」申告と文言が一致している
- 連絡先メールアドレスが有効
- URL がログイン不要で誰でも閲覧可能
- URL が `https://` で始まる
