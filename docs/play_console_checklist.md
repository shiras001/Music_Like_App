# Play Console 提出チェックリスト

このチェックリストは Play Console にアプリをアップロードする前に確認すべき主な項目です。

- アプリ本体
  - リリース用 AAB（署名済み）を用意済みか。
  - `android/app/src/main/AndroidManifest.xml` の権限・meta-data（AdMob App ID 等）が正しいか。

- プライバシー & データ
  - 公開プライバシーポリシー URL が有効であるか（`docs/privacy-policy.md` を公開済み）。
  - Data safety（データの扱い）フォームの内容を整理済みか（広告識別子、アナリティクス等）。

- 広告
  - UMP による同意取得が組み込まれているか（初回起動で表示）。
  - AdMob のアプリID/ユニットID が正しいか（デバッグIDではない）。
  - 広告配置がクリック誘導を生まないか（下記広告チェックリスト参照）。

- ストア掲載情報
  - アプリ名、短い説明、長い説明（多言語）を準備済みか。
  - スクリーンショット（必要サイズ）、アイコン、プロモーショングラフィックを用意。
  - 連絡先メール / プライバシーポリシー URL を設定。

- 法的・年齢関連
  - ターゲット年齢を決定し、児童向け（COPPA）該当の有無を確認。
  - 必要なら追加同意（親の同意等）や年齢制限を実装。

- その他
  - コンテンツレーティング用の回答を用意。
  - リリースノートを準備。
