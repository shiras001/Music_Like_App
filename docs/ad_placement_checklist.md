# 広告配置チェックリスト

広告がポリシー違反にならないためのチェックポイント。

- 表示場所
  - 誤クリックを誘発する場所（重要な操作ボタン付近、画面下のナビゲーションボタン付近）に広告を置いていないか。
  - コンテンツと広告の区別が明確か（ラベルや余白）。

- タイミング
  - フルスクリーン広告（インタースティシャル）を意図せず頻繁に表示していないか。
  - 操作直後に突然表示されないか（例: 再生開始ボタンを押した直後）。

- 動作
  - クリックで別コンテンツやストアへ遷移する挙動が明確か。
  - リワード広告は報酬の条件が明確で、詐欺的ではないか。

- 技術面
  - テスト用の広告ユニットではなく、本番ユニットでレビューを行う準備があるか。
  - UMP による同意がない場合は個人向け広告を配信しない/非個人化広告へフォールバックするか。

推奨対応: 実際の画面キャプチャを用意し、広告が配置される複数の画面での動作をスクリーン録画して保存しておくと審査が早く済みます。
