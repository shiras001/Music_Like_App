# 歌詞・楽曲の著作権リスク報告書

作成日: 2026-02-14

概要:
- リポジトリ内で歌詞（LRC）をローカルファイルとして読み込む機能が実装されています（`lib/data/lrc_service.dart`）。
- アプリには YouTube 動画から音声を抽出・保存する実装が含まれます（`lib/data/youtube_service.dart`、`youtube_explode_dart` 使用）。

発見されたリスク:
1.. 歌詞（LRC）の取り扱い
  - 現在はユーザーが選択したローカル LRC ファイルを読み込む仕様で、アプリ自体が外部歌詞DBから歌詞を取得して表示する実装は見つかりませんでした。
  - ただし、ユーザーが著作権で保護された歌詞ファイルをアップロード・表示する場合、表示権（出版権等）に関するライセンスが必要になるケースがあります。

推奨対応（優先度順）:
A. 歌詞表示の扱い（中優先）
  1. アプリが外部歌詞APIやスクレイピングで歌詞を自動取得しないことを確認し、将来追加する場合は歌詞提供元との明示的なライセンス契約を結ぶ。
  2. ユーザーがローカルで提供した歌詞ファイルのみ表示する仕様であることをストア説明やプライバシーポリシーに明記する（既にプライバシーポリシーに記載あり）。
  3. 歌詞編集・共有機能を追加する場合は、共有機能に対して権利確認フローを組み込む。

B. ストア提出時のドキュメント
  1. Play Console の「コンテンツの適合性」や「著作権」セクションで、アプリがユーザー提供のローカルファイルのみを扱う旨を明記する。
  2. YouTube ダウンロード機能を無効化しない場合は、審査上の説明・法的根拠を準備する（かなり厳しい）。

実装/運用チェックリスト (開発者向け):
- [ ] `docs/privacy-policy.md` に「ユーザーがアップロードしたローカル歌詞ファイルのみ表示する」旨を明記済み（既に記載あり）。
- [ ] ストア向け説明文に歌詞とダウンロード機能の取り扱いを明示する。

結論:
- LRC のローカル読み込み自体は一般的に問題になりにくい。
