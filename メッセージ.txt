了解です 👍
**Windowsのみ ＋ App Store公開なし ＋ AltStore で個人インストール**ですね。

この場合は **App Store用のDistribution証明書は不要** です。
必要なのは：

> ✅ Apple ID
> ✅ 無料のDevelopment証明書
> ✅ Development用Provisioning Profile
> ✅ IPAファイル

しかも実は――
**GitHub Actionsで署名済みIPAを作る必要はほぼありません。**

---

# 🎯 一番シンプルな結論

Windowsのみなら：

> 🔹 Flutterで「未署名IPA」を作る
> 🔹 AltStoreが自動で署名してくれる

これが最も簡単です。

---

# 🧭 全体の流れ（Windows完結）

① Apple ID準備
② FlutterでIPA作成（署名なし）
③ AltStoreでインストール

---

# 🥇 STEP 1：Apple IDを用意

Apple Developer有料登録は不要です。

無料Apple IDでOK。

---

# 🥈 STEP 2：FlutterでIPAを作る（Windows）

まずFlutterが入っている前提です。

## iOSビルドの注意

⚠ iOSビルドは本来macOSが必要です。

しかし今回は：

> 💡 GitHub Actions（macOS runner）を使ってIPAを生成
> → 署名はAltStoreがやる

という方法を使います。

---

# 🥉 STEP 3：GitHub Actionsで「未署名IPA」を作る

### .github/workflows/ios-build.yml

```yaml
name: Build iOS IPA (Unsigned)

on:
  workflow_dispatch:

jobs:
  build:
    runs-on: macos-latest

    steps:
      - uses: actions/checkout@v4

      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.19.0'

      - run: flutter pub get

      - run: flutter build ipa --no-codesign

      - uses: actions/upload-artifact@v4
        with:
          name: ios-ipa
          path: build/ios/ipa/*.ipa
```

---

## ✅ これで何が起きる？

* Apple証明書不要
* Provisioning Profile不要
* exportOptions.plist不要
* Secrets不要

ただの未署名IPAが生成されます。

---

# 🏗 STEP 4：AltStoreでインストール

## 必要なもの

* Windows PC
* iTunes（Apple公式版）
* iCloud（Apple公式版）
* AltStore

※Microsoft Store版ではなくApple公式サイト版

---

## 手順

1. AltServerをPCにインストール
2. iPhoneをPCに接続
3. AltStoreをインストール
4. IPAをAltStoreに読み込ませる

AltStoreが：

* Apple IDでログイン
* 自動署名
* 7日間有効の開発署名

をやってくれます。

---

# ⚠ 制限事項

| 項目       | 内容     |
| -------- | ------ |
| 有効期限     | 7日間    |
| 同時インストール | 3アプリまで |
| 再署名      | 7日ごと   |

---

# 🚀 重要ポイント

Flutter側で

```
--no-codesign
```

を必ず付けること。

これがないと証明書エラーで止まります。

# 🔥 もっと楽にする方法

GitHub Actionsで毎回ビルドせずに：

* 変更時だけビルド
* Release作成時だけビルド

にするのがおすすめです。
